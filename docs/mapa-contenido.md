# Mapa de conservación del contenido

La versión editorial de una sola página permanece íntegra en el historial Git de `main` anterior a esta rama (`964d3c7`). Este mapa indica dónde se presenta ahora cada bloque académico. La fuente estructurada `src/data/content.js` conserva las tres jornadas, el cuestionario y las ocho referencias originales.

| Sección anterior | Vista nueva |
| --- | --- |
| Portada fotográfica | `index.html` |
| Contexto ecológico de Los Cóbanos | `diagnostico.html` |
| Evidencia 2021, 2025, 2026 y nota metodológica | `diagnostico.html` |
| Relación de causas e impactos | `impactos.html` |
| Acciones por público y tres propuestas | `soluciones.html` |
| Metas e indicadores por implementar | `soluciones.html` |
| Comparador ilustrativo y simulador | `aprende.html` |
| Compromisos y cuatro preguntas | `aprende.html` |
| Ocho fuentes, créditos y carácter académico | `referencias.html` |

Se conservan las distinciones entre evidencia local, información general del PNUMA y propuestas aún no ejecutadas. Las cifras de jornadas distintas no se suman. Las imágenes del comparador se identifican como ilustraciones y las fotografías mantienen créditos y licencias.
